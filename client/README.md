# scrum.lol

Scrum tools

## Planning Poker

Host creates a room. Players join, and vote on a story. Host can at anytime reveal cards.

### Features

* no registration
* live collab
* cards
* name of current story

### Future features

* timer
* history
* JIRA integration?
* Trello?

### Tech stack
* React95
* Websockets
* Node.js
* Vite
* local storage
  * host: room, story name
  * players: name
